# Security reporting

This is a public architecture reference with local planning and documentation-review tools. It is not a managed SOC or a live vulnerability-disclosure target.

Use GitHub's private vulnerability-reporting channel for this repository for a substantiated issue in its own code or accidental sensitive disclosure. Include the affected commit, reproducible synthetic input, observed behavior and scope. Do not put credentials, customer data or confidential incident details into public issues.

Do not test third-party or production systems without explicit authorization. Architecture concerns and proposed constraints can use a public issue with non-confidential examples.
