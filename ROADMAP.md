# Research direction through 2030

The dates describe intended research progression, not committed delivery or completed deployments.

| Period | Focus | Evidence gate |
|---|---|---|
| 2026 baseline | Layer decisions, archetypes, source traceability and bounded planning tools | Inspectable design and actual local model/record checks |
| 2027 | Selected environment pilots: source-to-case, tenant permissions and response authority | Named environment, permitted/denied cases and measured failure behavior |
| 2028 | Federated, remote and disconnected operation with complete recovery scope | Freshness, local dependencies, approved transfers and observed loss/restore evidence |
| 2029 | Crypto-purpose inventory, supported PQ migration experiments and stronger evidence custody | Implementation-specific compatibility plus explicit signature/key-establishment scope |
| 2030 | Maintained independently reproducible architecture and evidence portfolio | Separately attributed reviews, accepted operational decisions and current evidence |

Prioritize a bounded question and a reusable result. Recognition, provider adoption, upstream acceptance and client results are recorded only when separately evidenced.

Near-term gaps: no deployed event pipeline, real SIEM query benchmark, workload trace, learned-model evaluation, live responder, physical air-gap assurance, full-site recovery or independent SOC assessment is claimed by this release.
