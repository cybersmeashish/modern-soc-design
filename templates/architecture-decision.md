# Architecture decision record

Reusable record fields; unfilled items remain unknown until an accountable owner supplies evidence. Do not treat this template as a completed assessment.

| Field | Value / evidence |
|---|---|
| Stable decision ID and layer/pattern IDs | To be supplied for the actual scope |
| Context and hard constraints | To be supplied for the actual scope |
| Alternatives and rejected options | To be supplied for the actual scope |
| Selected arrangement and why | To be supplied for the actual scope |
| Trust/authority/data/evidence boundaries | To be supplied for the actual scope |
| Trade-offs and failure behavior | To be supplied for the actual scope |
| Proposed owner and accepted real owner | To be supplied for the actual scope |
| Validation method and expected cases | To be supplied for the actual scope |
| Actual observations or explicit unknowns | To be supplied for the actual scope |
| Acceptance/review trigger and source/version | To be supplied for the actual scope |

Example context: a fictional remote site permits local read-only investigation while central connectivity is missing. Any claimed local operation still needs environment observation and owner acceptance.
