# SOC design brief

Reusable record fields; unfilled items remain unknown until an accountable owner supplies evidence. Do not treat this template as a completed assessment.

| Field | Value / evidence |
|---|---|
| Service/mission and harm | To be supplied for the actual scope |
| Entity, tenants, jurisdictions and obligations | To be supplied for the actual scope |
| Coverage versus staffed/on-call response | To be supplied for the actual scope |
| Selected/composed patterns and all-layer scope | To be supplied for the actual scope |
| Trusted/untrusted inputs and excluded visibility | To be supplied for the actual scope |
| Data/operator/key/support/supplier/recovery boundaries | To be supplied for the actual scope |
| Critical dependencies and degraded modes | To be supplied for the actual scope |
| Independent response rights and consequences | To be supplied for the actual scope |
| Capacity/cost/staffing assumptions | To be supplied for the actual scope |
| Acceptance evidence, actual owners and residual decisions | To be supplied for the actual scope |

Example context: a fictional remote site permits local read-only investigation while central connectivity is missing. Any claimed local operation still needs environment observation and owner acceptance.
