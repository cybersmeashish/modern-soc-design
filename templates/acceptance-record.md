# Scoped acceptance evidence

Reusable record fields; unfilled items remain unknown until an accountable owner supplies evidence. Do not treat this template as a completed assessment.

| Field | Value / evidence |
|---|---|
| Claim and evidence stage | To be supplied for the actual scope |
| Actual service/environment/tenant scope | To be supplied for the actual scope |
| Responsible owner and authorized test bounds | To be supplied for the actual scope |
| Source inputs, versions and hashes | To be supplied for the actual scope |
| Expected allowed/denied/degraded/recovery cases | To be supplied for the actual scope |
| Method, timestamp and actual outputs | To be supplied for the actual scope |
| Failed/indeterminate observations | To be supplied for the actual scope |
| Limits and remaining dependencies | To be supplied for the actual scope |
| Reviewer/owner acceptance or block decision | To be supplied for the actual scope |
| Expiry/change trigger | To be supplied for the actual scope |

Example context: a fictional remote site permits local read-only investigation while central connectivity is missing. Any claimed local operation still needs environment observation and owner acceptance.
