# Terms and distinctions

| Term | Meaning in this reference |
|---|---|
| SOC | Security operations center: people, decisions, data and systems supporting security operations |
| SIEM | Security information and event management; a component, not the complete SOC |
| SOAR | Security orchestration, automation and response; execution still needs independent authority |
| XDR | Extended detection and response across a provider-defined source/capability set |
| MDR | Managed detection and response with explicitly shared enterprise/provider responsibilities |
| MSSP | Managed security service provider, potentially serving separately authorized tenants |
| UEBA | User and entity behavior analytics; statistical signals do not create permission |
| RAG | Retrieval-augmented generation; retrieve only evidence permitted for the originating context |
| EPS | Events per second; average, peak and processing assumptions are distinct |
| FTE | Full-time-equivalent staffing, with coverage and workload modeled separately |
| RPO | Recovery point objective; desired loss tolerance, distinct from measured missing data |
| RTO | Recovery time objective; desired restoration deadline, distinct from observed restore time |
| SLO/SLA | Service objectives/commitments that require precise scope, measurement and ownership |
| IOC | Indicator of compromise; a match alone does not establish attribution or complete incident context |
| TLP | Traffic Light Protocol sharing markings; markings do not authenticate a recipient or grant access |
| Freshness | Current/delayed/missing/unverified evidence, with stated time and uncertainty assumptions |
| Sovereignty | Separately reviewed data/operator/key/support/supplier/disclosure/recovery boundaries |
| Disconnected | Connectivity condition; it does not by itself establish identity trust, authority or sovereignty |
| Documentation-valid | No selected static record contradiction found; not a secure or accepted deployment |
| Tested local | Scoped observation of the model/tool, distinct from environment and independent assurance |
